# GLOSSARY

This glossary contains short definitions for common cybersecurity terms used across this repository.

- IOC — Indicator of Compromise: forensic artifacts (hashes, IPs, domains) that indicate a security incident.
- CVE — Common Vulnerabilities and Exposures: public identifier for a known vulnerability.
- CVSS — Common Vulnerability Scoring System: numeric severity score for vulnerabilities.
- YARA — Rules used to identify malware families via pattern matching.
- TTP — Tactics, Techniques, and Procedures: attacker behavior description (ATT&CK-style).
- C2 — Command and Control: infrastructure used by attackers to control compromised hosts.
- PoC — Proof of Concept: a demonstration that a vulnerability can be exploited.
