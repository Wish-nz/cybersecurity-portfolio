Intrusion Detection Systems (IDS)

- An IDS monitors system and network activity, similar to home intrusion sensors that detect when an object touches a sound wave.
- It collects and analyzes system information for abnormal activities and sends alerts to appropriate channels and personnel if something unusual is detected.

Intrusion Prevention Systems (IPS)

- An IPS has all the capabilities of an IDS but can also take action to stop an intrusion, much like a jewelry store window sensor that triggers a steel roll-up door to prevent unauthorized entry.
- Many tools, such as Snort, Zeek, Kismet, Sagan, and Suricata, can perform both IDS and IPS functions.
