SIEM: Centralized Security Monitoring

- SIEM tools gather and analyze log data from various sources like intrusion detection systems, firewalls, and applications to provide a comprehensive overview of network activity.
- They act like a car's dashboard, presenting critical information and alerts from numerous network components in a single, accessible platform.

The SIEM Process

- **Data Collection and Aggregation:** SIEM tools collect vast amounts of log data from different sources and centralize it in one location.
- **Data Normalization and Analysis:** The collected raw data is then normalized by removing non-essential attributes and creating consistency, making it easier to search and analyze for security incidents against predefined rules.

SIEM vs. SOAR

- While SIEM tools focus on collecting, analyzing, and reporting security events for human review, Security Orchestration, Automation, and Response (SOAR) tools automate the analysis and response to these events.
- SOAR can also manage and track multiple incidents as a single case, offering a centralized view of security events.
