The Purpose of Detection Tools

- Detection tools function similarly to home security systems, monitoring and protecting networks and systems from unauthorized access.
- They continuously monitor for suspicious activity, triggering alerts to notify security professionals of potential intrusions.

Intrusion Detection Systems (IDS)

- An IDS monitors system activity and alerts on possible intrusions without stopping or preventing the activity.
- Security analysts investigate alerts generated by an IDS, which can include true positives (correctly detected attacks), true negatives (no malicious activity), false positives (incorrectly detected threats), and false negatives (undetected malicious activity).

Intrusion Prevention Systems (IPS) and Endpoint Detection and Response (EDR)

- An IPS monitors for intrusive activity and takes action to stop it, often having both detection and prevention capabilities.
- EDR tools monitor, record, and analyze endpoint system activity, using behavioral analysis and automation to identify and respond to suspicious activity on devices like computers and phones.
