Attacker's Perspective on Data Exfiltration

- Attackers first gain initial access, often through social engineering tactics like phishing, to compromise a system.
- After gaining access, attackers perform "lateral movement" to explore the network, expand their access, and identify valuable assets such as sensitive data.

Preparing and Exfiltrating Data

- Once valuable assets are identified, attackers collect, package, and reduce the data size to hide it and bypass security controls.
- Finally, attackers exfiltrate the data to their chosen destination, which can be done through various methods like emailing stolen data to themselves.

Defending Against Data Exfiltration

- Security teams must prevent initial attacker access, for example, by implementing multi-factor authentication to protect against phishing.
- Continuous network monitoring is crucial to detect suspicious activities, such as multiple user logins from unusual IP addresses, and to identify indicators of unusual data collection like large internal file transfers or external uploads.
