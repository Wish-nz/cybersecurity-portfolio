Understanding Network Packets

- Network traffic is divided into packets, which are like addressed envelopes containing delivery information such as sender/receiver IP addresses and packet type.
- Packets have multiple components: a header (with network protocol, port, source/destination IP), a payload (the actual data), and a footer (signifying the end of the packet).

Capturing Network Traffic

- Packet sniffers, also known as network protocol analyzers, are tools used to capture and analyze data traffic within a network.
- A packet capture (P-cap) is a file containing intercepted data packets, providing a detailed snapshot of network communications for incident investigation.
