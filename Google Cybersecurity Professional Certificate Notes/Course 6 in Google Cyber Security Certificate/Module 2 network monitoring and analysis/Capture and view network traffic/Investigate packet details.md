Internet Protocol (IP) Packets

- IP packets are the foundation of data exchange over a network, and IP ensures that packets reach their destinations.
- There are two versions of IP: IPv4 and IPv6, each with different header structures.

IPv4 and IPv6 Headers

- **IPv4 Headers:** Contain thirteen fields, including Version, Internet Header Length (IHL), Type of Service (ToS), Total Length, Identification, Flags, Fragment Offset, Time to Live (TTL), Protocol, Header Checksum, Source Address, Destination Address, and Options.
- **IPv6 Headers:** Contain eight fields, including Version, Traffic Class, Flow Label, Payload Length, Next Header, Hop Limit, Source Address, and Destination Address.

Wireshark for Packet Analysis

- Wireshark is an open-source network protocol analyzer with a graphical user interface (GUI) that helps visualize network communications.
- Display filters in Wireshark allow you to apply filters to packet capture files to find specific information based on protocols, IP addresses, ports, and other packet properties.
