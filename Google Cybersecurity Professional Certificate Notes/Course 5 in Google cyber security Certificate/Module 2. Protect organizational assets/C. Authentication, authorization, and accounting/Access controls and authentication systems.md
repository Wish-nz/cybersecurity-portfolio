Access Controls and the AAA Framework

- Access controls are security measures that manage who or what can access information, ensuring confidentiality, integrity, and availability.
- These controls are typically broken down into three functions: authentication, authorization, and accounting (AAA framework).

Authentication Factors

- Authentication verifies a user's identity and can be based on three factors: knowledge, ownership, and characteristic.
- **Knowledge** refers to something the user knows, such as a password or a security question answer.
- **Ownership** refers to something the user possesses, like a one-time passcode (OTP) sent via text or email.
- **Characteristic** refers to something the user is, such as biometric data like a fingerprint or facial scan.

Enhancing Authentication

- **Single Sign-On (SSO)** streamlines the authentication process by allowing users to log in once to access multiple resources, improving convenience.
- **Multi-Factor Authentication (MFA)** strengthens security by requiring users to verify their identity using two or more independent credentials, such as combining knowledge and ownership factors.
