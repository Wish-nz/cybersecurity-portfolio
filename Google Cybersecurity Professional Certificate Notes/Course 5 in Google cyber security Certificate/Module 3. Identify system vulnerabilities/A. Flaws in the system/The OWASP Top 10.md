What is OWASP?

- OWASP is a non-profit foundation dedicated to improving software security through an open platform where security professionals share information, tools, and events.
- The OWASP Top 10 is a key resource published since 2003, raising awareness about the most targeted web vulnerabilities, primarily for new or custom software.

Common Vulnerabilities in the OWASP Top 10

- **Broken Access Control & Cryptographic Failures:** These involve inadequate restrictions on user actions and insufficient encryption of sensitive data, respectively, leading to unauthorized access or data breaches.
- **Injection & Insecure Design:** Injection attacks insert malicious code into applications, while insecure design refers to a lack of built-in security controls during development, making applications vulnerable to various threats.
- **Security Misconfiguration & Vulnerable/Outdated Components:** These issues arise from improperly set security settings or the use of unmaintained open-source libraries, increasing the risk of exploitation.
- **Identification/Authentication Failures & Software/Data Integrity Failures:** Problems with recognizing user identities and inadequate review of software updates can lead to unauthorized access or the delivery of malicious software.
- **Security Logging/Monitoring Failures & Server-Side Request Forgery (SSRF):** Insufficient logging and monitoring hinder incident response, while SSRF allows attackers to manipulate server operations to access unauthorized data.
