Understanding Vulnerabilities and Exposures

- A **vulnerability** is a weakness in a system, while an **exposure** is a mistake that can be exploited by a threat.
- The CVE list is a public dictionary of known vulnerabilities and exposures, used by organizations to enhance their security.

The CVE List and Its Criteria

- The CVE list was created by the MITRE Corporation to standardize the identification and categorization of vulnerabilities and exposures.
- For a vulnerability to be assigned a CVE ID, it must be independent, recognized as a security risk, supported by evidence, and affect only one codebase.

National Vulnerability Database (NVD) and CVSS

- The NIST National Vulnerabilities Database (NVD) further tests CVEs and uses the Common Vulnerability Scoring System (CVSS) to rate the severity of vulnerabilities.
- CVSS scores, ranging from 0-10, help security teams prioritize patching efforts, with scores above 9.0 indicating critical risks.
