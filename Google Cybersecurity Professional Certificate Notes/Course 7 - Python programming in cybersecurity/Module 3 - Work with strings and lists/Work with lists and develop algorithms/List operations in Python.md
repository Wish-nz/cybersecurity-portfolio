Creating and Accessing Lists

- Lists store multiple data pieces in a single variable, defined by comma-separated items within square brackets.
- Elements in a list are accessed using an index, starting from zero for the first element.

Modifying Lists

- Unlike strings, lists are mutable, meaning their elements can be changed, added, or removed after creation.
- The `insert()` method adds an element at a specific position, shifting existing elements.

Combining and Removing List Elements

- Lists can be combined using the `+` operator, which concatenates them.
- The `remove()` method deletes the first occurrence of a specified element from a list.
