List Data in a Security Setting

- Lists are a fundamental data structure in Python, used to store collections of data in sequential form.
- In cybersecurity, lists can store various data types like usernames, IP addresses, URLs, and device IDs, enabling efficient manipulation and iteration.

Working with Indices in Lists

- Similar to strings, elements in a list are accessed using indices, which start at 0.
- Bracket notation allows you to extract individual elements or slices (sublists) from a list, and unlike strings, lists are mutable, meaning you can change their elements using bracket notation.

List Methods

- Python provides several built-in methods for working with lists:
    - The `.insert()` method adds an element at a specified index, shifting existing elements.
    - The `.remove()` method deletes the first occurrence of a specified element.
    - The `.append()` method adds an element to the end of the list.
    - The `.index()` method returns the index of the first occurrence of a specified element.
