String Fundamentals

- Strings are ordered sequences of characters, written in Python using either single or double quotation marks.
- The `str()` function converts other data types, such as integers or floats, into strings, enabling string-specific operations.

Basic String Operations

- The `len()` function returns the number of characters in a string, useful for validating data like IPv4 addresses.
- String concatenation, using the `+` operator, joins two or more strings together.

String Methods

- Methods are functions specific to a data type; for strings, they are called using a dot notation after the string.
- Common string methods include `upper()` and `lower()`, which return copies of the string in all uppercase or all lowercase letters, respectively.
