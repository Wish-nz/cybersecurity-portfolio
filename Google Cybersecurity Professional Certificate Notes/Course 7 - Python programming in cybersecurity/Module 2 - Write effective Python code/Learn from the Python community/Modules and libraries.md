Libraries and Modules

- A library is a collection of modules that provide reusable code.
- A module is a Python file containing functions, variables, classes, and other runnable code, helping to save time and improve code readability.

Python Standard Library

- The Python Standard Library is a comprehensive collection of pre-packaged Python code.
- Examples include the `re` module for pattern searching, the `csv` module for working with CSV files, and `glob` and `os` modules for command-line interaction.

External Libraries

- Beyond the Standard Library, external libraries can be downloaded for specialized tasks.
- Examples include Beautiful Soup for parsing HTML and NumPy for arrays and mathematical computations, which are useful for tasks like network traffic analysis and log file parsing in cybersecurity.
