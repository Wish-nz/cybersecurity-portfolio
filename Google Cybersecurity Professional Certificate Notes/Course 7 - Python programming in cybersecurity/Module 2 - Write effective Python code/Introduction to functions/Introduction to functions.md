What is a Function?

- A function is a section of code designed to be reused within a program, similar to how a dishwasher automates dishwashing.
- Functions help automate repetitive tasks, making programs more efficient and effective.

Benefits of Using Functions

- Functions can be called multiple times from anywhere in a program, reducing the need to write the same code repeatedly.
- Changes made directly within a function are applied everywhere the function is used, simplifying updates and maintenance.

Types of Functions

- **Built-in functions** are pre-existing in Python, such as the `print()` function, and are available by default.
- **User-defined functions** are created by programmers to meet specific needs, acting as mini-programs within a larger program.
