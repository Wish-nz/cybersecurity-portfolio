How Conditional Statements Work

- A conditional statement evaluates code to determine if it meets specific conditions, returning `True` or `False`.
- Comparison operators like `==` (equal to), `!=` (not equal to), `>` (greater than), `<` (less than), `>=` (greater than or equal to), and `<=` (less than or equal to) are used to compare values.

Using `if`, `else`, and `elif`

- An `if` statement starts a conditional block, executing its indented body if the condition is `True`.
- The `else` keyword provides an alternative action to be performed if all preceding conditions in the statement are `False`.
- `elif` (short for "else if") allows for multiple alternative conditions to be checked sequentially if previous conditions are `False`.

Logical Operators for Multiple Conditions

- The `and` operator requires both conditions it connects to be `True` for the overall condition to be `True`.
- The `or` operator requires only one of the conditions it connects to be `True` for the overall condition to be `True`.
- The `not` operator negates a condition, making a `True` condition `False` and a `False` condition `True`.
