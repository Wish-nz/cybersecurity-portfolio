While Loop Fundamentals

- While loops repeatedly execute a set of instructions as long as a specified condition remains true.
- The loop continues until the condition becomes false, at which point the loop stops.

Structure of a While Loop

- A while loop begins with the `while` keyword, followed by a condition that evaluates to `True` or `False`, and ends with a colon.
- The loop variable, which controls the number of iterations, must be assigned a value _before_ the while loop begins, unlike in for loops where it can be created within the loop statement.

While Loop Body and Iteration

- The body of a while loop is indented and contains the actions to be performed during each iteration.
- Since while loops do not have a built-in sequence to iterate through, you must explicitly define how the loop variable changes within the loop's body to ensure the loop eventually terminates.
