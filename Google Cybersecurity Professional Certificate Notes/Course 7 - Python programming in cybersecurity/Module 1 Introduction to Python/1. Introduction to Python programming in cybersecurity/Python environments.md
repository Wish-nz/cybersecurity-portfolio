Python Environments

- **Notebooks:** Online interfaces for writing, storing, and running code, allowing for both code execution and documentation.
- **Integrated Development Environments (IDEs):** Software applications that provide editing assistance, error correction, and a graphical user interface for building programs.
- **Command Line:** A text-based interface that uses commands to interact with the computer, allowing access to files and directories, including Python code.

Notebook Components

- **Code Cells:** Sections within a notebook specifically designed for writing and executing Python code.
- **Markdown Cells:** Sections used for describing the code and formatting text using markdown language.

Common Notebook Environments

- **Jupyter Notebook:** A popular open-source web application that allows you to create and share documents containing live code, equations, visualizations, and narrative text.
- **Google Colaboratory (Colab):** A free cloud-based Jupyter notebook environment that allows you to write and execute Python code through your browser.
