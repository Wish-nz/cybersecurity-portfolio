Scripts vs. Programs

- A **script** in Python is comparable to a theater script, focusing on the specific lines of code that will be executed.
- A **program** encompasses the entire production, including design decisions like lighting and costumes, similar to how programming involves various design choices beyond just the code.

Writing Your First Python Code

- **Comments** are notes within the code, starting with a hash symbol (`#`), explaining the programmer's intent.
- The `print()` function is used to display output on the screen, with the desired output placed inside parentheses.

Understanding Syntax

- **String data** (text) must be enclosed in quotation marks when used with the `print()` function.
- **Syntax** refers to the set of rules that dictate the correct structure of a computing language, ensuring the code can be understood and executed by the computer.
