Core Data Types

- **String**: An ordered sequence of characters enclosed in quotation marks, used for text.
- **List**: A mutable, ordered collection of data elements of various types, enclosed in square brackets.

Numerical and Logical Data Types

- **Integer**: Whole numbers without decimal points, used for counting and mathematical operations.
- **Float**: Numbers with decimal points, used for precise numerical calculations.
- **Boolean**: Represents one of two values: `True` or `False`, often used for logical comparisons.

Advanced Data Types

- **Tuple**: An immutable, ordered collection of data, enclosed in parentheses, useful for fixed data like software identifiers.
- **Dictionary**: A collection of key-value pairs, enclosed in curly brackets, for storing and retrieving data using unique keys.
- **Set**: An unordered collection of unique values, enclosed in curly brackets, ensuring no duplicate elements.
