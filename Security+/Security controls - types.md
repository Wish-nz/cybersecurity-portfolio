# Security Control Types

Deterrent controls discourage unwanted actions by making potential offenders think twice, such as signage warning against certain behaviors.
Preventative controls physically block or restrict actions, like locked doors or login requirements to prevent unauthorized access.
Detection and Correction

Detective controls help identify and investigate security incidents by tracking what happened, when, and how.
Corrective controls restore systems to their original state after an incident, often using backups to recover from damage like ransomware attacks.
Compensating and Directive Controls

Compensating controls address weaknesses in other controls, for example, multifactor authentication compensates for weak passwords.
Directive controls guide user behavior by enforcing policies and procedures, such as training employees on security practices.
Real-World Example

Retail stores use a combination of these controls: deterrent signs and employees, preventative security racks, detective cameras, corrective actions by security staff, directive employee training, and compensating entry gates to prevent shoplifting.
